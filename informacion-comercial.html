Compras y medios de pago

Los productos del catálogo muestran los precios publicados por SOLUCAR MÁS. El carrito y el paso de pago consultan el catálogo actualizado. Si el precio cambia, la operación debe detenerse para que revises el nuevo valor. El pago mediante Webpay se inicia y verifica a través de un servicio seguro, siempre que esté habilitado y correctamente configurado.

Los productos pueden requerir confirmación de disponibilidad y compatibilidad. Si no estás seguro de que un repuesto corresponda a tu vehículo, solicita orientación antes de comprar.

La autorización de una tarjeta no se considera confirmación de compra hasta que el sistema haya verificado la respuesta de la transacción. Guarda el número de orden y consulta el estado si hay dudas; evita repetir un pago cuya situación no conoces.

Despachos, entrega y compatibilidad

Los precios publicados y el subtotal del carrito corresponden a productos; no incorporan despacho. La cobertura, costo y plazo del envío se coordinan de manera individual cuando corresponde. Antes de pagar, solicita el costo de despacho si necesitas entrega a domicilio.

Para artículos dependientes de un vehículo, pueden requerirse marca, modelo, año, versión y número de parte. Las imágenes son orientativas cuando se identifican como referenciales.

Garantía legal, cambios y devoluciones

Los derechos de los consumidores que correspondan conforme a la normativa chilena se respetarán. En caso de defecto o incumplimiento, comunícate con nosotros indicando tu número de pedido, el artículo y el problema. Te informaremos el procedimiento aplicable a tu caso.

El régimen legal de garantía, la posibilidad de retracto y sus excepciones dependen de la naturaleza de la compra y las condiciones jurídicas aplicables. Ninguna información de esta web pretende limitar derechos irrenunciables de consumidores.

Contacta a contacto@solucarmas.cl para iniciar una solicitud.

Privacidad y tratamiento de datos

Cuando envías una cotización o consulta, podemos usar tu nombre, correo, teléfono, patente, comuna y descripción de la solicitud para responderla, buscar los datos del vehículo disponibles y dar seguimiento a la atención. Cuando creas una cuenta, sus datos y registros asociados se gestionan con el servicio de autenticación y base de datos configurado en la web.

Para el funcionamiento del servicio se utilizan proveedores tecnológicos, como Supabase para autenticación y almacenamiento, Resend para mensajes transaccionales cuando esté configurado, y la integración de consulta de patentes cuando se encuentre disponible. Las transacciones con tarjeta, cuando están habilitadas, se realizan mediante Transbank; el sitio no solicita que ingreses aquí los datos completos de tu tarjeta.

El navegador almacena la selección del tema y el carrito para conservar tus preferencias. La disponibilidad de funciones externas puede cambiar y no se garantiza que una patente tenga todos los datos o el VIN.

Para consultas sobre tus datos personales, solicitudes de acceso o modificación, escribe a contacto@solucarmas.cl. También puedes solicitar información adicional sobre conservación, acceso y tratamiento escribiéndonos a ese mismo correo.
