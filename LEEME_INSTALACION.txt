SOLUCAR MÁS — VERSIÓN 2 / ZONA DE CLIENTES
===========================================

QUÉ CAMBIA
-----------
- Tu logo original en assets/logo-claro.png y assets/logo-oscuro.png.
- Inicio y Tienda esencial muestran el nombre cuando hay sesión verificada.
- Nueva cuenta.html, con registro, inicio de sesión, recuperación de contraseña,
  panel personal, datos de contacto y despacho, vehículos e historial de compras.
- Mensajes más útiles cuando el navegador bloquea la conexión con Supabase.
- Formularios de pedidos y cotizaciones se pueden rellenar con datos guardados.
- Correo de verificación y recuperación con estilo SOLUCAR MÁS.

PASO 1 — GITHUB PAGES
---------------------
1. Haz una copia de seguridad de los archivos antiguos.
2. Abre GitHub y el repositorio que publica solucarmas.cl.
3. Sube todos los archivos y carpetas de este ZIP a la RAÍZ del repositorio,
   sin crear una carpeta extra SOLUCAR_MAS_V2.
4. Reemplaza index.html, tienda.html, cuenta.html, app.js, styles.css,
   cuenta.js, cuenta.css, supabase-config.js y añade auth-nav.js, assets/ y supabase/.
5. Conserva el CNAME que ya contiene solucarmas.cl.
6. Haz Commit changes y luego recarga con Ctrl+F5.

PASO 2 — SUPABASE: TABLAS Y SEGURIDAD (OBLIGATORIO PARA MI CUENTA)
------------------------------------------------------------------
1. Entra en https://supabase.com/dashboard
2. Abre tu proyecto > SQL Editor > New query.
3. Copia TODO el archivo supabase/esquema.sql y pulsa Run.
4. Verifica que aparezcan las tablas:
   public.customer_profiles, public.customer_vehicles, public.customer_orders.
5. IMPORTANTE: el SQL habilita Row Level Security (RLS).
   Cada cliente puede gestionar únicamente sus propios datos y vehículos;
   los pedidos solo pueden leerse, NO insertarse desde el navegador.
6. No cambies esas políticas por "using (true)" ni publiques claves secretas.

PASO 3 — CONFIRMACIÓN DE EMAIL
------------------------------
1. Supabase > Authentication > Sign In / Providers > Email: Confirm email ON.
2. Authentication > URL Configuration:
   Site URL: https://solucarmas.cl
   Redirect URL: https://solucarmas.cl/cuenta.html
3. Para enviar correos a usuarios reales, configura Resend en SMTP de Supabase
   (Resend Domain Verified y credenciales SMTP secretas SOLO en Supabase).
4. Authentication > Emails > Templates > Confirm sign up:
   Subject: Bienvenido a SOLUCAR MÁS · Confirma tu correo
   HTML: copia supabase/correo-confirmacion.html y guarda.
5. Para "Reset Password" puedes usar:
   Subject: SOLUCAR MÁS · Recupera tu contraseña
   HTML: copia supabase/correo-recuperacion.html y guarda.
6. Los enlaces {{ .ConfirmationURL }} son variables REALES de Supabase:
   NO reemplazarlas por un enlace fijo y no enviarlas desde un HTML público.
7. Opcional: usa "Send test email" si Supabase lo ofrece.

PASO 4 — PRUEBAS
---------------
- Registra un correo nuevo, revisa la bandeja de entrada y Spam.
- Confirma el correo; entra a https://solucarmas.cl/cuenta.html.
- Inicia sesión, guarda tus datos y un vehículo.
- Vuelve a abrir Mi cuenta y verifica que se mantienen los datos.
- Cambia al modo oscuro y verifica el logo.
- Ve a index.html y tienda.html: deberá mostrar "Hola, [nombre]" al iniciar sesión.
- Abre otra sesión de prueba y comprueba que NO ve los datos del primero.
- Prueba la recuperación de contraseña.

BRAVE Y BLOQUEADORES
-------------------
- Edge ya funcionó en una prueba anterior. Brave puede bloquear las solicitudes
  a tu dominio de Supabase si sus Shields o extensiones lo consideran rastreador.
- El sitio ahora muestra un mensaje claro cuando esto ocurre, pero NINGÚN
  código HTML puede saltarse las protecciones de privacidad del navegador.
- Si un cliente lo experimenta, puede permitir esa conexión solo para
  solucarmas.cl o usar otro navegador. No recomendamos desactivar toda
  la protección de su navegador permanentemente.

HISTORIAL DE COMPRAS — LIMITACIÓN IMPORTANTE
--------------------------------------------
- La tienda actual usa un carrito local y prepara solicitudes por email.
  Esos correos NO son pagos ni pedidos guardados en la base de datos.
- La tabla customer_orders permite mostrar pedidos REALES vinculados a user_id
  cuando tú, como administrador, los registres desde un sistema seguro.
- Para ventas reales, agregar integración de pagos, backend, comprobante,
  confirmación de stock y proceso de pedidos. Nunca grabar una compra
  como pagada solo porque el cliente hizo clic en "Solicitar pedido".
- Los productos y precios de la tienda son demostrativos hasta actualizarlos.

AVISOS
------
- El logo nocturno mantiene la geometría de tu PNG y aclara las partes azules.
- El logo en correos se carga desde https://solucarmas.cl/assets/logo-oscuro.png;
  algunos clientes de correo bloquean imágenes remotas, así que el email
  está escrito para seguir siendo entendible sin imágenes.
- URL y publishableKey en supabase-config.js SON PÚBLICAS. Nunca poner ahí
  service_role, sb_secret, tokens de servidor ni contraseñas SMTP.
- Tu proyecto de Supabase existente está configurado en supabase-config.js.
  Verifica que su URL coincida con Project URL antes de publicar.
